# Agenda

A minimal agenda for every day of the year — tasks, notes, contacts, photos, reminders and a note highlighter. Everything is stored on your own device (browser storage). No account, no ads, no tracking.

**Live demo:** https://agendaapphelp.github.io/Agenda/

## Try it
1. Open the demo link in Chrome, Edge, Safari or Firefox (desktop or phone).
2. Create an agenda, add tasks to a day and set a reminder.
3. When asked, allow **notifications** so reminders can pop up and ring (sound plays after your first interaction with the page).
4. Optional: install it — Chrome/Edge "Install app", or Safari → Share → Add to Home Screen.

## Features
- 12 languages, 9 colour themes, light and dark
- Desktop dashboard and phone layout
- Reminders with alarm-style repeating sound and snooze
- Notes with a 4-colour highlighter, contacts with symbols, multi-photo notes, voice notes
- Trash with restore
